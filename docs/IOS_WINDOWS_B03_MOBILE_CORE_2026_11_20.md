# B03：核心手機流程整合驗收

日期：2026-11-20。基線 `c9bfe65`，承接 B01／B02；對應 [Windows 計畫](IOS_WINDOWS_EXECUTION_PLAN_2026_11_19.md) W03-01、W03-02。

**本機必要鏈路已驗收；原生裝置與真實供應商待補驗。** 本批沒有改正式 App、方案規則或雲端資料，也沒有推送、部署、執行遠端 SQL、建立原生專案或安裝 Capacitor。通過的是正式靜態 App 在隔離服務上的流程，不是 TestFlight／iPhone 通過。

## 共用範圍與環境

- 實際執行 `scripts/build-mobile.mjs --require-api-base` 的 production 靜態輸出，使用正式路由與元件，沒有操作 Demo。測試／救援路由從輸出移除。
- 同一個一次性 PostgreSQL 17、GoTrue、PostgREST 與合成老闆、另一品牌、出攤助手；沿用 B02 已捕獲的資料表、函式、安全與投影 trigger，加上原始 095／097。這是本機重建，不是當前託管 schema 的證明。
- 瀏覽器套用 390×844 手機視窗設定。截圖是工具輸出，未拿來證明原生螢幕、實際 CSS 像素或觸控尺寸；跨尺寸排版矩陣仍沿 B06／H01 補驗。
- `/auth/v1`、`/rest/v1` 接實際本機服務；`/api` 執行正式匯出的 handler。身分驗證、權益、SQL 與事件投影都實際執行。
- 手機 API 強制 HTTPS 的規則維持原樣。測試的公開 API 位址設為 `https://127.0.0.1:41430`，用瀏覽器開發工具將**指定 API fetch**轉送本機 HTTP；沒有忽略憑證或降低正式安全要求。TLS、ATS、Capacitor Origin CORS 與真實 Supabase HTTPS 是 H01／部署環境的補驗，不由此代理證明。
- 開啟已在捕獲 schema 中的縣市、期限、心得、現金、現金比較與財務核對旗標。照片供應商保持未配置；沒有使用正式 R2／Supabase 密鑰。
- 本輪 `out/` 含本機合成服務位址與公開 anon JWT，只供驗收，屬忽略產物，不能直接發布。B06 必須按交接的真實公開設定重新建置。

平台相關能力是網路／生命週期、登入儲存、選圖、檔案預覽／儲存；本批沿現有 `lib/platform` port，沒有把測試網路接線加進共用業務程式。

### 邊界與修正

1. 初版隔離接線使用 HTTP API，被手機 client 正確拒絕；改為上述僅測試用 HTTPS 位址與精確轉送。共享 client 的安全規則沒有修改。
2. 捕獲欄位清單沒有帶 SQL default，新增市集遇到 `markets.is_schedule_override` 非空錯誤。按 migration 069 補回本機 `DEFAULT false`；保留原待同步紀錄後自動重試成功，沒有另外建一筆。時間戳／UUID 預設也由 fixture 明確還原。這是測試重建的修正，不是正式站資料庫修正。
3. 第二 origin 的 GoTrue 預檢在此精簡代理中沒有可用 CORS header，停止該次 UI 登入；版本衝突改由獨立登入的實際 API 用戶端製造，再於原手機 UI 驗證。沒有把未完成的第二瀏覽器登入算通過，也沒有以此判定正式 Supabase CORS 有問題。
4. 「預覽 PDF」觸發瀏覽器工具安全政策阻擋，停止該入口操作，沒有繞過 `blob:` 限制。已下載檔案的五頁渲染只證明匯出內容，**不證明裝置內建預覽器／QuickLook 已驗收**。

本批沒有發現需要改動共用業務邏輯的確定缺陷。新增的是可重現的本機驗收工具；不是為了驗收新增正式測試入口。

- [機器證據](evidence/ios-windows-b03-mobile-core-2026-11-20.json)：保存實際 API 結果、檢查結果、檔案 SHA 與待驗邊界；不含登入 token、密鑰或正式營運資料。
