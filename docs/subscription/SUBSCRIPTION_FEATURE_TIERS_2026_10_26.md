# 訂閱功能分級：免費版、輕量版與高階版

日期：2026-10-26（Asia/Taipei）。狀態：三方案功能分界、價格基線與後台設定價格的需求已確認。使用者進一步授權設定頁的測試切換及依身分呈現功能，已進入[第一批實作](THREE_TIER_EXPERIENCE_IMPLEMENTATION_2026_10_26.md)；已加入 082 指定測試帳號雲端權益試行，並完成[本輪完整性補漏](SUBSCRIPTION_COMPLETENESS_AUDIT_2026_10_26.md)；未啟用全帳號商業限制或商店商品，也未實作正式付費／取消。整批測試驗收依使用者要求暫緩。

## 1. 最新決策與舊規格關係

- 免費版定位為市集行程、報名與出攤準備管理；不提供銷售、收入及經營統計。
- 使用者接受前輪提出的免費功能範圍，詳見第 2 節；不是只保留三個狀態按鈕。
- 新增輕量付費版，提供老闆本人記錄銷售與互動，詳見第 3 節。
- 此決策取代 2026-10-23「只有 Free 記錄版＋付費品牌工作室」作為後續功能分級的前提。
- 高階版採品牌經營與協作定位，NT$249／月、NT$2,490／年；接受的功能與席次基線見第 3.5 節。不能將高階功能自動納入輕量版。
- 本輪實作明確保留既有契約代碼 `free`／`pro`／`team`，分別映射免費／輕量／高階；僅共用模型與呈現變更，不重寫舊帳本、雲端訂閱或已成立的交易承諾。舊訂戶權益遷移、升降級處理仍須另行制定，不因代碼相同就假設歷史商業條件相同。

| 產品方案 | 主要用途 | 月繳基線 | 年繳基線 |
| --- | --- | --- | --- |
| 免費版 | 記得報了哪些市集，掌握錄取／繳費與準備 | 免費 | 免費 |
| 輕量版 | 一個人完整記錄生意，知道每場賣了多少 | NT$59 | NT$588，平均 NT$49／月 |
| 高階版 | 看懂值得投入的場次與商品，讓團隊一起營運 | NT$249 | NT$2,490，平均 NT$207.5／月 |

這些是目前核定的起始價格，不是永久價格常數。兩個付費方案的月／年牌價都須能由營運後台按價格版本與排程管理，詳見第 4 節。月均值僅輔助說明，實際年繳仍一次支付年費。

## 2. 免費版：市集安排與報名管理

產品承諾：幫攤商記得報了哪些市集、是否錄取、是否繳費，以及出攤前要準備什麼。

| 功能 | 已確認保留範圍 |
| --- | --- |
| 市集基本資料 | 新增／編輯名稱、日期、多日場次、縣市及自由地點 |
| 報名進度 | 已報名、等待錄取、已錄取，以及延期／取消與狀態更正 |
| 繳費紀錄 | 是否已繳、繳費期限、到期／逾期的 App 內提醒 |
| 繳費金額 | 報名費、攤位費及保證金可作報名／付款資料保留；不提供成本加總、利潤或費用比較 |
| 出攤時間 | 提前進場、報到、開始／結束時間，今日時間軸及基本進行／結束狀態；不以完成收款／盤點作為前提 |
| 首頁提醒 | 今日／近期場次、待繳費、待錄取及同日多場安排；保留待處理場數 |
| 清單與查找 | 查看過去／未來市集、搜尋與既有篩選、進入單場 |
| 備註 | 主辦／場地注意事項、停車、卸貨與報到位置等文字 |
| 個人出攤準備 | 場次待辦、勾選完成、準備範本；可選從心得另建個人待辦 |
| 私人出攤心得 | 單場記錄／閱讀、集中檢視與搜尋、日期／縣市篩選；無須先記帳，不附收入／成交／淨利摘要 |
| 固定出攤安排 | 重複營業安排、場地／縣市管理及既有場次調整 |
| 基本資料保存 | 帳號、雲端同步、既有離線暫存及同步狀態；不擴大原有離線寫入能力 |

### 分界

- 「待繳費 3 場／待錄取 6 場」屬操作提醒，不因有數字就列為付費統計。
- 縣市可用來分類／查找場次；營收、商品及經營表現的縣市分析不屬免費。
- 個人文字心得屬市集經驗；顧客互動計數、成交照片及其待補流程不屬免費。
- 免費待辦、備註及心得供 owner 個人使用；不能據此開放員工協作或分享私人心得。
- 首頁以今日／近期場次、報名／繳費提醒及新增市集為主；範本、心得、固定安排保留次要入口，不把所有免費功能堆到首屏。
- 免費場次數、心得數等額度沒有新決策，不由本次文件推定為有限或無限。

## 3. 輕量付費版：完整的單人出攤記錄工具（已確認）

「輕量付費版」為目前工作名稱；本輪沿用 pro 作為內部契約代碼，正式品牌名稱仍可另定。

產品承諾：一位老闆可以完整記錄一場生意，並知道今天賣了多少、現金是否相符。單人品牌可以長期使用；高階版以深入比較、經營分析與多人協作提供額外價值。

| 計費方式 | 使用者已確認價格 | 呈現要求 |
| --- | --- | --- |
| 月繳 | NT$59／月 | 按月計費 |
| 年繳 | NT$588／年 | 一次支付年費；可輔助顯示平均 NT$49／月，不得顯示成可每月扣 NT$49 |

### 3.1 使用者已接受的功能分界

| 功能 | 輕量版包含 | 留給高階版，不包含在輕量版 |
| --- | --- | --- |
| 免費功能 | 全部承接市集安排、報名／繳費、準備與私人心得功能 | — |
| 銷售記錄 | owner 快速金額、商品銷售、付款方式、補登、更正及撤回 | 員工共同記錄與角色分工 |
| 商品管理 | 名稱、售價、成本、基本庫存及銷售扣庫存 | 商品表現比較及進階經營分析 |
| 顧客互動 | owner 記錄詢問等互動，查看當日／單場次數 | 時段分布、轉換率與跨場比較 |
| 收入查看 | 當日／單場收入、成交筆數、付款方式小計及逐筆紀錄 | 趨勢、成長率、跨期間／跨場分析 |
| 基本月摘要 | 本月總收入與成交筆數 | 月份比較、圖表及深入拆解 |
| 成本與估計淨利 | 單場已記錄商品成本、攤位／設備費彙總、估計淨利及計算說明 | 市集獲利排名、地區／期間比較 |
| 現金紀錄 | 選填開／收攤現金、面額、現金銷售比較及差額 | 團隊交接核對、多人責任管理 |
| 商品封面 | 基本商品封面，協助現場辨識；容量另定 | 較高圖片額度或其他進階圖片用途，具體規格另定 |
| 歷史查閱 | 自己的歷史交易、單場成果與基本搜尋 | 跨場次彙整分析與完整結算報告 |
| 成交照片 | 不包含成交照片及其待補流程 | 成交照片、待補照片與協作查核 |
| 報告與協作 | 頁面內查看基本結果；單一 owner 使用 | 完整 PDF、進階報表、員工／manager 協作 |

高階欄位及第 3.5 節為已接受的分級方向，不代表功能全部已完成或已啟用；實際圖片額度、超額席次與正式名稱仍待制定。不能因分級表而把尚不存在的轉換率圖表、進階圖片能力或多人核對流程標成已交付。

### 3.2 基本結果與進階分析的明確分界

| 使用者想知道 | 分級 |
| --- | --- |
| 今天這場賣了多少、收款方式各多少 | 輕量版 |
| 這場現金有沒有差額 | 輕量版 |
| 這個月累積多少收入、成交幾筆 | 輕量版；單一月份加總不等於開放跨場比較分析 |
| 哪些市集值得再報名 | 高階比較／分析 |
| 哪些縣市、商品或時段表現較好 | 高階比較／分析 |
| 讓員工分工，同時限制敏感資料 | 高階協作 |

### 3.3 已接受的產品原則

- 記錄、修正、查看自己的紀錄是一套完整流程；不將基本總額或歷史交易藏到更高方案。
- 單場淨利沿用既有簡單模型：根據已記錄銷售利潤、固定成本與抽成估算；不因付費而保證成本完整。未填資料的限制清楚呈現，不新增採購、應收應付或專業會計流程。
- 現金盤點與對帳維持選填，可完全略過；差額不自動改寫收入、庫存或淨利。
- 不用很低的成交筆數或每月場次上限作為升級壓力，避免營業中被迫停止記錄；這不是無限量承諾，合理使用與實際額度另定。
- 月繳／年繳是相同功能的不同計費週期。owner 本人可用，不授予員工／manager 邀請、多人分工或私人心得分享權限。

### 3.4 仍待決定的細節

- 商品數、商品封面容量、圖片保存期，以及其他合理使用額度；不在未評估前承諾無限圖片。
- 高階方案圖片額度、超過內含席次的擴充方式與正式名稱；高階功能及內含席次基線見第 3.5 節。
- 舊 `free`／`pro`／`team` 對照、降級資料可讀／可改範圍、升降級計費及優惠資格。
- 基本月摘要、基本歷史搜尋等新分級對應目前頁面／讀取模型的具體實作；需求定案不代表程式已完成。

### 3.5 高階版：品牌經營與協作（已採用的方案基線）

包含免費版與輕量版全部功能，並增加：

| 領域 | 高階版範圍 |
| --- | --- |
| 市集成果 | 多場收入／成本／估計淨利比較、獲利排序，協助評估是否再參加 |
| 期間成果 | 自訂日期、月份比較、營收及估計淨利趨勢 |
| 縣市表現 | 場次、收入、估計淨利與平均表現比較 |
| 商品表現 | 銷量、營收及利潤貢獻比較 |
| 互動分析 | 時段分布、互動與成交關係；資料不足時不強行推論，具體指標需有可解釋定義 |
| 報告 | 完整結算報告與 PDF；不得把尚未完成的 Excel 匯出寫成已提供 |
| 成交照片 | 拍攝、補照片、查看與對應成交；容量與保存期另定，不宣稱照片可證明交易真實性 |
| 團隊 | 員工邀請、場次與角色分工、依權限記錄及查看資料 |
| 交接與追查 | 團隊交接筆記、共用待辦、辨識操作人員及紀錄來源；進階多人核對若未實作需另列待辦 |
| 圖片額度 | 較輕量版高的容量並支援成交照片；實際容量、上限處理及保存期仍待成本評估 |

收費以一個品牌工作空間為單位，由老闆訂閱。內含 1 位老闆＋3 位協作成員；manager、出攤助手及查看者均計入協作席次，員工不需各自購買。各人使用自己的帳號，不按手機／平板台數另收費，也不因此允許共用老闆憑證。超過 3 位成員的擴充方式尚未制定，不承諾無限員工。

品牌主私人心得仍保持私人；manager／員工的成本、總利潤與跨場資料依角色及範圍限制，不因高階訂閱而自動全部可見。App 營運後台權限與品牌協作權限分開，高階老闆不是 App 營運管理員。

此方案不延伸為 ERP；採購、薪資、完整會計、多倉調撥不是本次承諾。正式銷售時只列已完成可用的能力，規劃中功能不得當作立即可用的購買理由。

## 4. 優惠與其他價格政策

### 4.1 後台可設定價格：三方案持續保留的要求

- 免費版維持免費；輕量／高階的月費與年費分別管理。不能將其中一個方案或年費寫成永遠固定的價格，也不從月費自動推導實際年費。
- 後台按方案、計費週期、平台、地區、幣別保存價格版本、生效時間、發布狀態與歷史；目前 59／588、249／2490 作為初始核定基線，不作 runtime 唯一來源。
- App 價格展示使用已發布且適用的價格版本；年費月均值從該年費計算。原生購買確認使用已驗證的商店商品實價，後台設定與商店未對齊時不可提供錯價購買。
- 新客牌價、優惠到期銜接價格、舊客調價批次分開管理；調整新客價格不直接改既有訂戶的續訂條件。
- 既有月繳調價沿用至少提前 60 天通知的產品政策並符合商店要求；年繳保留已付當年度、符合條件的續訂才調整。保價、優惠承諾與通知紀錄不可被新版本覆寫。
- 優惠碼、期間與活動獨立版本管理，停用新領取不取消已成立權益。只授權 App 營運管理員設定價格，不能以品牌 owner／manager 權限操作。
- 後台可設定不等於任意數字立即成為商店售價；沿用平台映射、驗證、發布及部分失敗狀態。既有模型支援的例行價格／活動變更應不需改 App 原始碼；新增優惠類型或商店能力仍可能需要開發。
- 這是後台必須具備的需求，現階段尚未實作，不代表本次已建立可操作的價格管理頁。

### 4.2 已有活動及歷史承諾

- NT$588／年與 NT$59／月是本次確認的輕量版售價；NT$49 是年費月均值，不是首發優惠價。
- 不將既有品牌工作室的 199／1990 首發優惠或舊 `FERIA50` 自動套用到輕量版；新方案的優惠適用範圍、升級後首購資格及價差處理仍待定義。
- 既有可設定優惠活動、價格版本、新客牌價／優惠銜接價／舊客調價批次的後台方向保留，見 [價格與活動需求](SUBSCRIPTION_PRICING_PROMOTION_ADMIN_REQUIREMENTS_2026_10_23.md)。
- 本次不是實際漲價、購買或付費啟用，不重寫已成立的交易／價格承諾。

## 5. 後續實作邊界

功能矩陣及額度完整確認後，才規劃舊權益對照、降級後資料可讀／可改範圍，以及共用 client／server gate。不得只隱藏 UI 就宣稱方案已限制，亦不得因降級直接刪除既有銷售／心得／圖片。

權益、價格、驗證及同步契約維持共用；商店價格／購買／恢復經既有 `lib/platform` 邊界，不為 Web／iOS／Android 分別建立商業規則。本輪無平台 API、SQL、商店設定或測試操作。
