# 三方案功能呈現與本機測試切換

日期：2026-10-26（Asia/Taipei）。依使用者授權，在設定加入方案切換，開始將既有功能按免費／輕量／高階呈現。正式購買、扣款、取消、恢復商店購買及動態價格後台均不在本輪範圍。

## 方案映射與入口

- 沿用既有資料契約代碼：`free` → 免費版、`pro` → 輕量版、`team` → 高階版。本輪是明確的共用模型映射，不建立第二套瀏覽器方案偏好，也不重寫訂閱交易／帳本。
- `lib/subscription/subscription-plans.ts` 是功能定義；`subscription-access.ts` 將進階分析、完整報告與 PDF 的最低方案改為 `team`。付款介面與商店價格目錄沒有啟用。
- `experience.ts` 只從目前 owner 的有效伺服器 capability 判斷呈現；過期、不同 owner、無效或無來源時不猜測付費身分。角色授權仍獨立檢查。
- `SubscriptionExperienceProvider` 在受保護 App 內提供共同身分。切換後所有 capability hook 收到同一程序內的失效通知，先清舊結果再重讀；沒有新增 localStorage、裝置 API 或 client 端權益持久化。

設定的「訂閱身分測試」提供免費／輕量／高階及「還原帳號原有方案」。沿用既有 server-only 工具：已登入、明確開啟 server flag、loopback、非 Vercel 部署，最長 4 小時，程序重啟即還原。套用失敗不先標成成功；帳號／token 變動時不採用舊回應。

本機 `.env.local` 已開啟 `SUBSCRIPTION_SIMULATION_ENABLED=true`。基本點擊發現來源名稱差異造成 `cors_origin_denied`，已在本機既有 `APP_API_CORS_ALLOWED_ORIGINS` 加上 localhost／127.0.0.1 的 3000 port，保留其他值；沒有更改共用 CORS 規則或正式環境。設定值不包含於提交文件。

## 本輪已接線的功能呈現

| 表面 | 免費 | 輕量 | 高階 |

| 新增／編輯 | 保留基本資料與繳費金額，隱藏抽成／固定成本合計及設備成本區 | 成本／設備可用 | 成本／設備可用 |
| 商品直達網址 | 顯示具名方案限制與返回入口，不掛載商品管理頁 | 商品工具 | 商品工具 |

免費版的個人心得不依賴銷售資料；單場編輯、延期／取消／刪除仍沿原確認流程，收攤不強迫收款、對帳或心得。現金紀錄與既有銷售／圖片沒有因切換被清除。低階進入原照片 task 時不開啟照片工作流；回顧選到原照片頁籤時回基本成果。

輕量版基本月摘要使用共用 `basic-business-summary.ts`，從已限定 owner、排除撤回的成交事件按成交日期加總，支援舊手動總額的成交筆數，不按市集開始日期錯分月份。不做排名／成長率／跨場分析；標明目前已讀取紀錄與同步狀態。

## 重要邊界

- 模擬不修改 `subscription_accounts`、真實付款、staff 關係或 RLS，不讓測試 high 身分繞過雲端上傳、成員邀請、席次、角色或資料範圍規則。模擬只顯示 Team UI，不等於已授權雲端新增員工。
- 這是新方案呈現、共享讀取 gate 與本機測試的第一個實作切片；不能將其稱為正式付費防護已完成。Core 銷售／商品等雲端寫入的完整付費 enforcement、圖片額度、降級可讀／可改規則及受保護測試部署仍須另行完成；既有本機 cache 也不是藉隱藏 UI 就變成不可存取。
- 不自動刪除降級資料、不強制清瀏覽器、不登出、不啟動上傳或重試 worker，不修改既有事件 writer 或同步寫入路線。
- 後台價格設定需求保留；方案頁的 59／588、249／2490 僅明示規劃售價，未連接動態後台，也不是商店報價。
- 本機切換不能藉開啟 public flag 放到正式網站。將來若需線上測試，應採有授權的測試環境與 server 驗證，不能放寬成所有人都能自選付費權益。
