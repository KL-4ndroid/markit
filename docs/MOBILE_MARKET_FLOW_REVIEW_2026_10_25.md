# 手機完整出攤流程驗收與精簡

日期：2026-10-25（Asia/Taipei）。使用者已授權依手機體驗優先驗收及修正；正式 App 本機版本，未檢視或修改 Demo。

## 範圍與結果

依序操作首頁提醒 → 市集新增／報名進度 → 準備待辦 → 快速收款 → 現金盤點／比較 → 心得 → 收攤 → 集中回顧。以 390 寬手機為主，補 360／430 寬與 1440 桌面檢查。

使用既有測試 owner，新增兩個獨立具名測試場次；沒有改其他營運場次、商品庫存、訂閱或員工權限。這是瀏覽器尺寸驗收，不等同 iOS／Android 實機、OS 鍵盤、真正第二裝置或正式部署。
