# 外觀與主題：正式介面整理

日期：2026-10-30。本機實作；此文件不代表已部署線上。

## 名稱與位置

- 使用者可見的「主題實驗室」正式改名為「外觀與主題」。
- 入口：更多 → 個人化 → 外觀與主題。個人化區塊移至訂閱方案之前；既有老闆／員工入口與各方案權益不變。
- 「內建靈感」改稱「精選主題」；預設主題展示名稱由 JapaneseD 暖霧改為「暖霧日常」，另移除暮光主題描述中的設計參考來源。九套色票數值與 ID 保留。

## 操作與回饋

- 開啟後先看目前配色預覽、九套精選主題與既有收藏；手機雙欄、桌面三欄選擇。
- 套用任何精選／收藏配色，底部固定回饋列立即顯示「已套用『名稱』」約四秒，接著顯示持續可見的「目前配色：名稱」。提示使用 polite live region；再次套用同一組時也重新更新訊息與計時。
- 與目前色票相符的卡片以外框、勾選、使用中文字及 aria-pressed 表示，避免只靠全頁顏色變化猜測是否成功。
- 「完成」與原關閉按鈕都可返回更多；說明明確指出選擇後立即套用，並非等按完成才保存。
- 自訂 HEX、收藏保存、核心／互動對比檢查、恢復預設、JSON 匯入／匯出收進「進階調整」，保留原有能力。
- 對比不足的匯入／自訂配色仍是預覽；提供還原說明，沿用原安全保存及關閉還原規則，不把預覽誤稱為已永久套用。

## 相容性

保留 `ThemeLab`／`ThemeLabGate` 內部識別、原事件與 `feria.dev.theme-lab.v1` 儲存鍵，以及既有 15 個色票欄位、收藏、匯入／匯出格式。使用者可見名稱不必跟隨歷史程式名稱；這次不搬移資料或要求使用者重設配色。

這是共用設定介面的呈現與回饋調整，沒有新增裝置能力或瀏覽器專用 API；沿用現有外觀套用、保存及匯入匯出流程。沒有新增頁面、訂閱 gate、資料庫遷移或原生套件。
