# 九套主題：顏色與對比修正紀錄

日期：2026-10-30。承接 [原始稽核](THEME_WCAG_AUDIT_2026_10_30.md)；原稽核的數字保留為修正前證據。

## 已完成

- **共用按鈕**：主要與危險操作改用不透明的較深 hover 色。危險按鈕另外推導白字專用底色，避免自訂主題的「危險文字對卡片可讀」被誤當成「白字對危險底可讀」。
- **鍵盤焦點**：Button 採深色實線與卡片色間隔，逆色 IconButton 採白色外圈與深色間隔；一般 IconButton、說明入口、表單折疊與收入表格入口不再只以低透明度外圈表示焦點。
- **頁首**：移除共用頁首的白光及半透明漸層中段，為頁首推導保有對比餘裕的主／輔色階；市集、商品、照片視窗、首頁與共用頁首的小字使用不透明文字。半透明白底操作改為透明底白字，或卡片底深字；hover 不再鋪白色。FullScreenForm 額外白光一併移除。
- **每日收入趨勢**：以實心柱／外框柱表示高於平均／低於或等於平均，圖例同步；柱框和平均虛線改為不透明色。虛線後加卡片底，跨過實心柱時仍可辨識。固定柱形繪圖區高度，日期標籤放在繪圖區外；保留相同資料來源的可展開表格供觸控與鍵盤使用。未改收入或平均值算法。
- **資訊圖示與文字**：PWA 分享提示、測試救援畫面改用深色文字／圖示；保留原 `info` 色票與匯出格式，不再直接用其淡色當上述小字或必要圖示。
- **主題實驗室**：預覽頁首與實際頁首使用同一組推導色；原五項改稱「核心文字對比檢查」，新增可展開的 11 項互動情境檢查，分別標明 4.5:1／3:1 門檻。判定使用完整精度，顯示數字向下取兩位，避免未達標卻顯示達標門檻。通過／待調整仍有圖示與輔助文字。

## 相容性與範圍

九套主題及 15 個原始色票欄位保留。hover 與頁首色為推導的呈現 token，套用個人主題時一起更新，恢復預設時一起移除；不改既有 JSON、收藏、匯入／匯出、個人原始色碼。沒有切換或覆寫使用者目前的收藏配色。

**自訂色仍沿用五項核心保存條件**，不因擴充檢查而讓舊色票消失。11 項情境檢查是額外提示，可能對任意自訂色顯示「待調整」；因此「可儲存」不等於所有畫面都符合對比要求。後續如要提高自訂色保存門檻，需另外設計舊色票遷移與提示。

本次是共用呈現修正，沒有新增平台能力、瀏覽器 API、資料庫變更、訂閱或財務規則。沿用既有 Web 主題套用機制，色彩推導為純函式，原生打包可使用相同樣式與計算。Demo 和無關素材未修改。
